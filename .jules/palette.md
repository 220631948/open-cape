## 2024-08-11 - Add contextual ARIA labels to app navigation buttons
**Learning:** Generic icon-only navigation buttons in the primary layout (like a mobile menu toggle or a notifications bell) often lack contextual screen-reader announcements, particularly when their state changes (e.g., menu open/closed, or unread notification counts). Visual notification badges inside buttons can also be confusingly read out as standalone numbers.
**Action:** When auditing global layouts, explicitly ensure toggle buttons use `aria-expanded` and dynamic `aria-label`/`title` based on state. For buttons with visual notification counts, include the pluralized count logic within the parent button's `aria-label` and apply `aria-hidden="true"` to both the icon and the badge element to provide a clean, unified announcement.
