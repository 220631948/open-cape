## 2024-05-24 - React-map-gl inline array prop causes excessive rerenders\n**Learning:** Passing an inline array calculation directly to the `interactiveLayerIds` prop on react-map-gl Map component breaks referential equality and triggers extensive map re-evaluations, which in turn impacts application frame rates heavily.\n**Action:** Use `useMemo` to memoize the array constructed from dynamic state variables (like `activeLayers`), ensuring the prop maintains referential equality across component re-renders unless the dependencies actually change.
