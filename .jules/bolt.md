## 2026-07-24 - Memoize interactiveLayerIds in react-map-gl
**Learning:** In MapPage.tsx, generating `interactiveLayerIds` inline using `.map()` and `.filter()` creates a new array reference on every single component render. `react-map-gl` checks referential equality of props; passing a dynamically generated inline array forces unnecessary recalculations or event bindings under the hood on every render loop, which is extremely detrimental to rendering performance on interactive heavy-map implementations.
**Action:** Always wrap dynamically generated, non-primitive props intended for map component instances (like arrays and objects configuration) in a `useMemo` hook, specifying their exact dependencies (in this case `activeLayers`), ensuring that `react-map-gl` properly infers referential equality.
