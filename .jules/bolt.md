## 2026-07-25 - Memoize Map Component Props
**Learning:** In MapLibre React components, passing inline functions (like `onLoad`, `onData`) or inline arrays/objects (like `interactiveLayerIds`) directly to the `<Map>` component breaks referential equality on every re-render of the parent component. Because this application is a spatial analysis platform, the parent component (`MapPage.tsx`) contains a huge amount of state and re-renders frequently. Every re-render creates new instances of these props, forcing the underlying MapLibre instance to potentially re-evaluate interactions and re-bind event listeners, significantly degrading rendering performance.
**Action:** Always extract inline arrays/objects passed to the map into `useMemo` and inline functions into `useCallback`. This is especially crucial for props like `interactiveLayerIds` which control the fundamental interactive layer stack of the map instance.
