## 2024-05-18 - Preserving referential equality on complex inline react-map-gl properties
**Learning:** `react-map-gl` relies heavily on object reference equality to determine if an expensive map reconciliation needs to take place. An inline array inside the Map component's properties, such as `interactiveLayerIds={ [ ...activeLayers.map(...), ... ] }`, is recreated on every single render cycle of `MapPage.tsx`, causing the underlying Mapbox/Maplibre instance to continuously unbind and rebind layer interactions, producing significant main thread work.
**Action:** Always extract inline array calculations for `interactiveLayerIds` (and similar array/object properties) into a `useMemo` block, with proper dependencies. This prevents unnecessary reconciliations unless the dependency array (`activeLayers` in this case) actually changes.
