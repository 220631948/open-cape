## 2024-03-20 - Icon-Only Button Accessibility Pattern
**Learning:** The application has a widespread pattern of missing `aria-label` and `title` attributes on generic icon-only interactive elements (like `<Button size="icon">`) across the app.
**Action:** When implementing UX improvements, always verify that icon-only buttons include explicit `aria-label` and `title` properties for screen reader accessibility and hover tooltips.
